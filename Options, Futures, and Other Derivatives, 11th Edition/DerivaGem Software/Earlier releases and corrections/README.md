# Earlier DerivaGem releases and corrections

These materials accompany earlier editions of John Hull's books. The 4.00a package for OFOD 11th edition is in the parent folder. Original workbooks, package documentation, and executables are preserved unchanged.

| Folder or file | Contents and version |
| --- | --- |
| `4.00/` | Complete contents of `DG400.zip`: three workbooks and the original README. The package identifies OFOD 10th edition. |
| `2.01/` | Complete contents of `DerivaGem.zip`: three Excel workbooks, two OpenOffice `.ods` workbooks, and the original README. |
| `2.00/DG200.01.xls` | Original standalone workbook. Its title identifies the software as version 2.00 despite the filename. |
| `1.22 and 1.22a/Dg.exe` | Original self-extracting version 1.22 package. |
| `1.22 and 1.22a/DGA.exe` | Original self-extracting alternative version 1.22a package, as identified on Hull's archived site. |
| `Tab D Correction.xls` | Correction to the earlier Applications Builder's delta-and-gamma-hedging example. The worksheet refers to OFOD 7th edition, Problem 24.31. It is not an update to the 4.00a package. |

Keep the workbooks within each release together. The original self-extracting packages are retained as historical downloads; they were not executed during incorporation into this collection.

[Hull's software page, archived January 1, 2009](https://web.archive.org/web/20090101075055/http://www.rotman.utoronto.ca/%7Ehull/software/), documents the Tab D correction and the distinction between versions 1.22 and 1.22a. Later releases are identified by their original package READMEs and workbook title sheets.
