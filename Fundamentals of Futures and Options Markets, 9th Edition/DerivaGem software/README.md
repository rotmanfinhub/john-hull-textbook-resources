# DerivaGem 4.00a

This is the complete DerivaGem 4.00a package for *Fundamentals of Futures and Options Markets*, 9th edition, and *Options, Futures, and Other Derivatives*, 11th edition.

The original files are preserved unchanged:

- `DG400a.xls`: options calculator.
- `DG400 functions.xls`: functions for building applications.
- `DG400 Applications.xls`: example applications.
- `readme.txt`: the original package documentation.

Keep these files together. The files were extracted from `DG400a.zip`, linked from [Hull's software page, archived October 6, 2022](https://web.archive.org/web/20221006132404/http://www-2.rotman.utoronto.ca/~hull/software/).
