# Other risk-management software

This folder contains the bivariate-normal, eigenvalue/eigenvector, principal-components, and Gaussian-quadrature worksheets linked from [Hull's RMFI 6th-edition software page, archived May 15, 2023](https://web.archive.org/web/20230515130048/https://www-2.rotman.utoronto.ca/~hull/software/RMFIsoftware.htm).

## Additional operational-risk example

`OPRISKSIMULATION.xls` is an earlier operational-loss simulation worksheet, preserved unchanged. [Hull's software page, archived January 1, 2009](https://web.archive.org/web/20090101075055/http://www.rotman.utoronto.ca/%7Ehull/software/), links this exact filename as the calculator used to produce Figure 14.2 in *Risk Management and Financial Institutions*.

That archived page does not specify the edition. Figure 14.2 is an older reference and should not be treated as sixth-edition numbering. The workbook is included here as an additional example related to operational risk.
