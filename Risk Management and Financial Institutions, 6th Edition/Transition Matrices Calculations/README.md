# Credit transition matrix worksheets

Both files are preserved unchanged and contain different transition probabilities.

| File | Edition association |
| --- | --- |
| `TransitionMatrixCalculations4e.xls` | The version linked by Hull's sixth-edition software page. Use this file for the sixth-edition collection; the `4e` filename was retained by the original site. |
| `TransitionMatrixCalculations.xls` | An earlier example linked by Hull's third-edition software page. It is retained alongside the later version for comparison. |

Sources: [third-edition software page, archived March 29, 2012](https://web.archive.org/web/20120329033422/http://www.rotman.utoronto.ca/%7Ehull/software/RMFIsoftware.htm), and [sixth-edition software page, archived May 15, 2023](https://web.archive.org/web/20230515130048/https://www-2.rotman.utoronto.ca/~hull/software/RMFIsoftware.htm).
